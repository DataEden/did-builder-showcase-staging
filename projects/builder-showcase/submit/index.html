    Submit a Builder Project

    The Builder Showcase is in early testing. Submissions are reviewed before publication to confirm that each project is appropriate, clearly documented, and submitted by someone who owns, contributed to, or has permission to share the work.

    What to prepare

    Before submitting, make sure you have:

    • a public GitHub repository
    • a clear README
    • a short project description
    • a list of tools or technologies used
    • permission to share the project publicly
    • a raw README URL for the project you want reviewed

    Submission fields

    This form collects your name, email, GitHub information, project details, repository link, raw README URL, optional live demo link, and confirmation that you have permission to submit the project.

    README URL guidance

    A raw README URL helps the Builder Showcase load the correct project documentation, especially for monorepos, portfolio repos, or projects inside folders.

    A raw README URL usually looks like this:

    https://raw.githubusercontent.com/username/repository/main/path/to/project/README.md

    To find it:

    1. Open the project README on GitHub.
    2. Click Raw.
    3. Copy the browser URL.
    4. Paste it into the Raw README URL field.

    README and Live Demo Rules

    README files should use standard Markdown: headings, paragraphs, lists, tables, code blocks, images, and normal links.

    For safety, the Builder Showcase does not support embedded scripts, iframes, forms, custom inputs, object/embed tags, inline event handlers, or javascript links. These may be removed during rendering.

    Use the Live Demo URL field for deployed apps, dashboards, videos, walkthroughs, or hosted demos instead of embedding them directly in the README.

    Live demo links are reviewed before rendering.
